# Where We Linger — website starter

A responsive editorial travel/landscape blog homepage based on the supplied visual reference.

## Included
- `index.html` — page structure and content
- `styles.css` — responsive editorial styling
- `script.js` — mobile navigation, search overlay and newsletter interaction

## Run it
Open `index.html` in a browser. The photography is loaded from Unsplash, so an internet connection is needed for the photos.

## Easy customisation
Search/replace the sample article titles, descriptions and image URLs in `index.html`.
Change the main colours and typography at the top of `styles.css`.

The design is intentionally built as a clean, editable starting point rather than a screenshot pasted into a webpage.
