# Where We Linger
A responsive editorial homepage inspired by the supplied visual reference. Built with HTML, CSS and a small amount of JavaScript for navigation, search overlay and newsletter feedback.

## Files
- index.html — homepage
- styles.css — responsive design system and layout
- script.js — menu, search and newsletter interactions

Open index.html locally or publish the repository with GitHub Pages. Photography is currently loaded from Unsplash and requires an internet connection.
